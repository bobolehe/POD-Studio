# 统一界面样式

范围：index.html、product-batch.html、batch.html、listing.html 四个操作页面；历史验收图册保留原样。

主题源文件：theme.css。运行 sync-theme.py 后，会将同一套 CSS 内联同步到四个页面，兼容现有两个本地静态服务，不需要重启服务。首次改造前页面保存在 before-*.html。

统一深蓝页眉、当前页高亮导航、蓝色主按钮、表单边框、卡片、表格和状态提示；所有功能导航使用当前标签页。800px 以下采用单列布局。首页预览区在桌面窗口随滚动保持可见。

验收：四页实际导航和截图检查、窄窗口无横向页面溢出、批量页9款产品加载、自选模板初始化、加拿大币种切换、首页测试图案渲染与导出按钮启用。原控件 ID 和脚本保持不变。商品模型测试通过；内存文件系统模拟4000组合生成/续跑、停止及失败处理测试通过。未重复执行亚马逊提交或实际4000张图片渲染。

注意：现有批量程序以首页文件内容计算任务版本；首页样式修改也会改变版本。旧批次目录保留，新任务可能使用新的版本目录。
