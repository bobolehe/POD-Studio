# V5 分层模板验收报告

## 原定目标
修复横版/竖版帆布画四边及折角的露底、突角问题，在上传、包边、拖动缩放、旋转、导出功能保持可用的前提下，提供可人工验收的模板。

## 完成情况
- [x] 结构重做：原 JPG 仅用于商品缩略图与形状参考，不参与最终合成。
- [x] 独立轮廓：圆角路径通过 4 倍采样生成共享遮罩，正面与侧面共同使用，没有两个多边形独立裁切造成的缝。
- [x] 独立光影、投影：重新建立程序化明暗和外部柔和投影，不从原图暗部猜轮廓。
- [x] 映射：正面透视映射，左侧镜像取样；边缘一次覆盖率混合。
- [x] 两款22项测试通过：纯黑/纯红的全覆盖区域无灰白漏点；遮罩外无图案像素写入；缩放、旋转、复位、导出与查看图层恢复正常。
- [x] 实际文件上传：compare-source.png，1800×1200，成功显示尺寸及预览。
- [x] 视觉自检：浏览器验收页查看两款四角约200%放大图，没有再观察到旧版的浅色露底条带和突角。
- [ ] 用户视觉验收：待 Ethan 确认真实感、厚度、投影及实际业务素材效果。

## 发现的问题与修正
| 程度 | 问题 | 根本原因 | 修正 |
|---|---|---|---|
| 必须改正 | index.html 旧版将JPG明暗与不准确区域一起叠加 | 把已经合成的商品照片当成分层模板 | template-v5.js 独立轮廓、光影、投影和一次合成 |
| 必须改正 | V4取暗部把投影当成边缘 | 灰度不能唯一确定实物轮廓 | 撤回灰度追边，不再采原图边缘 |
| 应当改正 | 首轮仅整体预览及按钮测试 | 技术通过被当成视觉通过 | 22项测试 + 200%四角 + 旧新对照，视觉待验收 |

## 做得好的地方
保留旧版本及对应输出，明确近似模板与原厂模板的区别，测试没有上传到聚鼎或保存订单。

## 限制
此版是依据产品外形重新构建的预览模板，不是恢复了聚鼎PSD；明暗、圆角和投影与原图有差异。仅包括这两个固定视角可见的正面和左侧，不是生产包边展开图。技术测试证明图层合成的一致性，不等于真实产品尺寸或视觉已获用户认可。

## 验收方法
打开 http://127.0.0.1:8766/acceptance-v5.html 。按图层 → 同图对照 → 四角放大 → 极端素材依次检查。
重点：四边无连续浅色露底，四角无尖角/灰块，包边衔接合理，投影与厚度观感可接受。使用实际业务素材再导出检查。
