# 整产品批量生成
入口：http://127.0.0.1:8766/product-batch.html
选择一个产品会自动包含该产品所有模板，选择500张素材后选择输出文件夹并开始。8模板输出4000张；16模板输出8000张。
采用浏览器串行渲染+File System Access API逐张落盘，不在内存积累全部PNG。需Chrome/Edge支持目录写入；任务运行时保持网页打开，不属于关闭网页后继续执行的服务端任务。
输出在所选文件夹的product-SKU-版本目录下，按素材名和内容摘要分组。相同内容同名文件自动复用。每张PNG配有done.json校验记录；续跑时验证SHA256后跳过，损坏或缺失的文件重新生成。重新选择原素材与输出文件夹即可继续。单张50MB、15000px限制沿用原渲染器。保留失败显示和最近任务计数。
验证：真实浏览器8模板全部生成，第二次跳过8张；破坏1张输出后重生成1张、跳过7张。500素材×8模板的4000任务队列采用模拟渲染/内存目录测试，覆盖续跑、停止、失败继续；并非已实际渲染4000张高清图。原生文件夹授权对话框由用户选择，自动测试使用浏览器专用测试存储。
