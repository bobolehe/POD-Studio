# 保存结果 → 选择记录 → 生成商品表格

## 使用顺序

1. 单张工作台：上传素材、调整场景后点击“保存当前效果到生成列表”。保存原始素材及当前场景快照，不会擅自改变其他场景。
2. 整产品批量生成：选择多张素材和一个产品，保存方式选择“保存到生成列表”。逐张生成该产品全部场景。原来的“仅保存到自选文件夹”仍保留，但该模式不会登记到列表。
3. 生成列表：查看素材、场景缩略图、保存时间和完整状态，可下载素材及单张效果图。勾选已保存的帆布画，再点击“使用所选记录生成表格”。
4. 商品表格：为每条素材填写英文主题和描述，选择英国或加拿大，共用下方可编辑规格/报价/包装配置，检查后生成草稿。不重新上传或渲染图片。

## 保存与恢复

- 素材、图片和记录保存在 `D:\codex\聚鼎设计页功能调研\library-data`。请整体备份此目录；仅清空浏览器缓存不会删除这些文件。
- 本地服务为127.0.0.1:8767，沿用启动商品表格服务的脚本。没有上传公网或第三方存储。
- 每条记录使用独立UUID目录。图片落盘后记录摘要；所有预期图片存在且校验通过才显示“已保存”。中断记录保留，使用相同素材、产品和渲染版本重新执行可续存。
- 完整记录为图像快照；同样的单张效果或同样的批量版本重复保存会复用。不同修改版本会保留独立记录。生成表格时，同一素材+产品的多个版本应只选择一个，避免重复刊登。
- 英文主题/描述的输入草稿目前保存在此浏览器本地存储；导出后的文案也包含在输出plan.json。清除浏览器数据后可能需要重新填写文案。产品规格配置仍支持JSON保存/加载。

## 商品表格范围

- 仅横版3:2和竖版2:3帆布画可用于建表。其他产品可以保存和查看图片，但不能被勾选建表。
- 每条所选素材生成1父体及所配置的子体；SKU由保存记录ID确定，重复导出同一记录保持稳定。
- 单次最多500条素材、10000行；图片批量保存逐张处理，不把全部PNG累积在内存中。
- 保存单个场景不等于保存全部模板。缺少所需场景时，清单标记“图片待补”，不伪造本地图片路径。
- 本地图片不等于亚马逊可访问的公网URL。当前列表建表将公网图片字段留空，另附本地图片对应清单；上传前需托管并补齐。没有自动上架。
- 输出在 `D:\codex\聚鼎设计页功能调研\listing\outputs`，包含XLSM、校验报告、plan.json和图片对应清单。
