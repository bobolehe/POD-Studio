# 批量生成

入口：http://127.0.0.1:8766/batch.html

多张JPG/PNG素材 × 选中模板，自动居中铺满，输出1000×1000 PNG。九产品82模板可勾选。复用现有渲染器，无Python服务、外部上传或额外第三方库。

单张<=50MB，最大15000px；每批<=200组合，累计PNG<=300MB，超出停止并保留结果。逐张处理，停止在当前图片完成后生效；坏图记录失败并继续。刷新或关闭页面会丢失尚未下载的结果。

ZIP包含序号_素材名/SKU/模板.png和生成记录.json。同名素材使用输入序号区分。ZIP采用标准Store格式、中文UTF-8路径和CRC32。

验证：两张同名素材跨九产品18图；ZIP独立解包、CRC、中文路径及PNG尺寸检查通过；82模板生成通过；坏图继续通过；停止后保留1/82。抽取保温杯、竖毛毯、竖挂画与历史单张图像对照，RGB各通道平均绝对差均小于0.17/255，非逐像素完全相同，不声称零差异。

限制：不继承单张页面手动裁切；暂无断点续跑、后台常驻、大于1000px高清输出、文件夹直接写入。海量任务另需持久化后台队列。

回滚：index.before-batch.html覆盖index.html；batch.html和batch.js可保留存档。
